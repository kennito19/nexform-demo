REQUIREMENTS
------------
- PHP 8.1 or higher
- PDO extension (built-in on all hosts)
- SQLite3 extension (or MySQL)
- FileInfo extension (built-in on all hosts)
- Apache or Nginx web server


QUICK INSTALL
-------------
1. Upload the contents of the /nexform/ folder to your server.
2. Set /uploads/ and /data/ to writable (chmod 755).
3. Open config.php and enter your email, SMTP, and admin password.
4. Visit your site – the form works immediately with SQLite.
5. Admin panel: yoursite.com/nexform/admin/  (use NF_ADMIN_PASSWORD)
