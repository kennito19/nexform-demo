Introduction

NexForm is a powerful, responsive Ajax PHP form builder that you can embed into any web page in minutes. It ships with four stunning themes, a multi-step wizard engine, conditional field logic, drag-and-drop file uploads, built-in spam protection, zero-config SQLite storage, and a password-protected admin panel.

🧙

Multi-Step Wizard

Split long forms into steps with animated progress bars and back/next navigation.

🎨

4 Beautiful Themes

Light, Dark, Material Design, and Glassmorphism – all via CSS custom properties.

👁

Conditional Logic

Show or hide fields dynamically based on the value of other fields.

📁

Drag & Drop Uploads

Secure file upload with MIME validation, size limits, and inline preview.

🛡

3 Captcha Modes

Honeypot, reCAPTCHA v2 checkbox, reCAPTCHA v3 invisible – one config line.

📊

Admin Panel + CSV

Browse, filter, delete submissions. Export any form to CSV for Excel.

Installation

  1. Upload files. Upload the entire nexform/ folder (the product root) to your web server. Any directory works, e.g. /public_html/nexform/ or /public_html/contact/.
  2. Set permissions. Make the uploads/ and data/ directories writable by the server (chmod 755 or 775): 
    chmod 755 uploads/
chmod 755 data/
  3. Edit config.php. Open config.php in a text editor and set your email address, SMTP credentials (optional), admin password, and captcha mode.
  4. Visit your site. Open the URL in a browser. The contact form should be working immediately. SQLite database is created automatically on first submission.
  5. Access the admin panel at yoursite.com/nexform/admin/ using the password you set in config.php.
Tip – Embed in an existing pageYou can use any example as a starting point. Copy one of the example PHP files to your project, include config.php and nexform/autoload.php, render the form, and add the CSS/JS links.

Configuration

All settings live in config.php in the project root. Open it and edit the define() calls.

Mail Settings

// Recipient – who receives new submissions
define('NF_MAIL_TO',         'you@yourdomain.com');

// From name shown in the email

define('NF_MAIL_FROM_EMAIL', 'noreply@yourdomain.com');

Builder API

NexForm uses a fluent PHP builder. Every field method returns $this, allowing you to chain calls to build a form in a few lines.

Basic Usage

<?php
require_once 'config.php';
require_once 'nexform/autoload.php';

use NexForm\NexForm;

$form = new NexForm('contact');       // 'contact' = form identifier (used for DB + rate limiting)
$form->action('process.php')          // Where POST is sent
     ->theme('nf-theme-light')        // Theme class
     ->text('name', 'Your Name', ['rules' => ['required', 'minlen:2']])
     ->email('email', 'Email', ['rules' => ['required', 'email']])
     ->textarea('message', 'Message', ['rules' => ['required', 'minlen:10']])
     ->submit('Send Message');

echo $form->render();                 // Outputs the <form> HTML

Constructor Options

$form = new NexForm('form-id');
$form->action('process.php')          // POST action URL
     ->theme('nf-theme-dark')         // Theme (see Themes section)
     ->steps(3)                        // Enable multi-step with N steps
     ->submit('Send', '<icon html>')  // Button label + optional icon HTML
     ->attr('id', 'my-form');          // Add arbitrary <form> attributes

Field Options

Every field method accepts an $options array as its last parameter:

OptionTypeDescription
rulesarrayValidation rules – see Validation section
filtersarraySanitisation filters – see Filters section
placeholderstringHTML placeholder attribute
helpstringHelp text shown below the field
defaultstringPre-filled value
classstringExtra CSS class on the field wrapper. Use nf-half for 50% width.
idstringOverride the generated element ID
stepintWhich step this field belongs to (multi-step forms)
show_ifarrayConditional logic: ['field_name' => 'expected_value']
maxlenintOn textarea: enables live character counter
rowsintOn textarea: number of visible rows
maxintOn rating: maximum stars (default 5)

The field label is automatically used in error messages. Set a clear label for best results:

->email('email', 'Email Address', ['rules' => ['required', 'email']])

Themes

Switch themes by passing a theme class to ->theme():

$form->theme('nf-theme-light');    // White, indigo accent
$form->theme('nf-theme-dark');     // Dark navy, purple accent
$form->theme('nf-theme-material'); // Google Material Design
$form->theme('nf-theme-glass');    // Frosted glass / glassmorphism

Custom Theming via CSS Variables

Every visual property is a CSS custom property. Override any variable on the theme class:

/* In your own stylesheet, loaded after nexform.css */
.nf-theme-light {
    --nf-primary:       #e11d48;   /* Rose accent */
    --nf-primary-hover: #be123c;
    --nf-radius:        20px;      /* More rounded */
    --nf-bg-field:      #fdf2f8;   /* Pink-tinted inputs */
}

Multi-Step Forms

Enable multi-step mode with ->steps(N) and mark each field with 'step' => N:

$form = new NexForm('contact');
$form->action('process.php')
     ->steps(3)                     // 3 steps total

     // Step 1
     ->step(1, 'Personal Info')     // Creates a step heading
     ->text('name',  'Name',   ['rules' => ['required'], 'step' => 1])
     ->email('email','Email',  ['rules' => ['required', 'email'], 'step' => 1])

     // Step 2
     ->step(2, 'Your Message')
     ->select('subject','Subject', [...], ['step' => 2])
     ->textarea('message','Message', ['step' => 2])

     // Step 3
     ->step(3, 'Review & Send')
     ->file('attachment','Attachment', ['step' => 3])
     ->submit('Submit');
Validation per stepClicking "Next" validates only the fields in the current step. Users cannot advance with errors. The final "Submit" validates everything server-side.

Conditional Field Logic

Use 'show_if' to show a field only when another field has a specific value:

->select('contact_method', 'Preferred Contact', [
    'email' => 'Email',
    'phone' => 'Phone',
    'post'  => 'Post',
])

// Only shown when contact_method === 'phone'
->tel('phone', 'Phone Number', [
    'show_if' => ['contact_method' => 'phone'],
])

// Only shown when contact_method === 'post'
->textarea('address', 'Postal Address', [
    'show_if' => ['contact_method' => 'post'],
])

Multiple conditions can be set – all must be true for the field to show:

->text('vat_number', 'VAT Number', [
    'show_if' => ['account_type' => 'business', 'country' => 'gb'],
])
NoteWhen a hidden field has required in its rules, the required constraint is automatically disabled while the field is hidden to prevent phantom validation errors.

Enable Uploads in Config

Add a File Field

->file('attachment', 'Attach a File', [
    'rules' => [
        'file_max:' . (5 * 1024 * 1024),
        'file_types:pdf,doc,docx,jpg,png',
    ],
])

Security

  • Uploaded files are stored with random names (prevents overwrite and path traversal)
  • MIME type is validated against a whitelist (prevents extension spoofing)
  • The uploads/ directory has .htaccess blocking PHP execution
  • Files are stored outside web root if you set NF_UPLOAD_DIR to an absolute path above public_html

Spam Protection

Honeypot (Default – Recommended)

A hidden field that only bots fill in. No user interaction required. Works silently.

define('NF_CAPTCHA_MODE', 'honeypot');

reCAPTCHA v2 (Checkbox)

define('NF_CAPTCHA_MODE',          'recaptcha_v2');
define('NF_RECAPTCHA_SITE_KEY',    'your-site-key');
define('NF_RECAPTCHA_SECRET_KEY',  'your-secret-key');

reCAPTCHA v3 (Invisible)

define('NF_CAPTCHA_MODE',          'recaptcha_v3');
define('NF_RECAPTCHA_SITE_KEY',    'your-site-key');
define('NF_RECAPTCHA_SECRET_KEY',  'your-secret-key');
define('NF_RECAPTCHA_V3_SCORE',    0.5);   // 0.0 = most permissive, 1.0 = most strict
Get reCAPTCHA KeysVisit google.com/recaptcha/admin, register your domain, and copy the Site Key and Secret Key into config.php.

Database Schema

    id          INTEGER PRIMARY KEY AUTOINCREMENT,
    form_id     VARCHAR(100) NOT NULL DEFAULT 'default',
    fields      TEXT NOT NULL,          -- JSON encoded field values

Rate Limiting

Prevents spam floods by limiting submissions per IP per time window:

define('NF_RATE_LIMIT_ENABLED', true);
define('NF_RATE_LIMIT_MAX',     5);     // Max 5 submissions
define('NF_RATE_LIMIT_WINDOW',  600);   // Per 10 minutes (600 seconds)

Rate limit data is stored in data/rate_limit.json. The file is managed automatically and old entries are pruned on each request.

Admin Panel

Access the admin panel at: yoursite.com/nexform/admin/

  1. Enter the password defined in NF_ADMIN_PASSWORD in config.php.
  2. Use the form filter dropdown to view submissions for a specific form only.
  3. Click Export CSV to download all visible submissions.
  4. Click Delete on any row to permanently remove a submission.
  5. Click Log out to end your admin session.
SecurityChange NF_ADMIN_PASSWORD from the default immediately. For extra security, consider restricting access to /admin/ by IP address in your .htaccess.

CSV Export

Click the Export CSV button in the admin panel, or access directly:

yoursite.com/nexform/admin/export.php           -- All forms
yoursite.com/nexform/admin/export.php?form_id=contact  -- Contact form only

The exported CSV includes a UTF-8 BOM for perfect Excel compatibility and contains all submission fields as columns.

Email & SMTP

Using PHP mail()

define('NF_MAIL_TRANSPORT', 'mail');  // default

Works on most shared hosting environments where PHP's mail() function is configured by the server.

Using SMTP

SMTP gives you more reliable delivery. NexForm's built-in SMTP client handles TLS/STARTTLS and AUTH LOGIN. For complex setups (OAuth2, advanced TLS), install PHPMailer:

composer require phpmailer/phpmailer

Then replace the sendSmtp() method in nexform/Mailer.php with the PHPMailer equivalent (see the comments in the file).

Callbacks & Events

const form = new NexForm('#my-form', {

    // Called before the AJAX request is sent
    // Return false to abort submission
    beforeSubmit: function(formData) {
        console.log('About to submit', formData);
        // return false; // would cancel submission
    },

    // Called when the server returns success: true
    successCallback: function(response) {
        console.log('Success:', response.message);
        // Redirect, show a modal, fire analytics, etc.
        gtag('event', 'form_submit', { 'form_id': 'contact' });
    },

    // Called when the server returns success: false
    errorCallback: function(response) {
        console.log('Error:', response.message, response.errors);
    },
});

Public Methods

const nf = new NexForm('#my-form');

nf.submit();   // Programmatically submit (runs validation + Ajax)
nf.reset();    // Clear all fields, errors, and the response message

Frequently Asked Questions

Can I put multiple forms on one page?

Yes. Create multiple NexForm instances with different form IDs and render each. Each form manages its own CSRF token and submissions independently.

How do I embed the form in an existing PHP page?

<?php
require_once '/path/to/nexform/config.php';
require_once '/path/to/nexform/nexform/autoload.php';
use NexForm\NexForm;
$form = new NexForm('contact');
$form->action('/path/to/nexform/process.php')
     // ... add fields ...
     ->submit('Send');
echo $form->render();
?>
<!-- In <head>: -->
<link rel="stylesheet" href="/path/to/nexform/assets/css/nexform.css">
<!-- Before </body>: -->
<script src="/path/to/nexform/assets/js/nexform.js"></script>
<script>new NexForm('.nf-form');</script>

Can I use it in a plain HTML page?

Yes. Set the form's action to process.php. NexForm works with JavaScript for Ajax submissions but degrades gracefully – if JS is disabled, the form submits normally to process.php which handles everything server-side.

How do I add a new form type?

  1. Create a new example page, e.g. examples/survey.php, with a new NexForm('survey') instance.
  2. Create the field map file examples/forms/survey.php with the $fieldMap variable.
  3. That's it — process.php automatically loads the field map by form ID.

How do I change the success message?

The message is returned from process.php – find the last line: jsonResponse(true, 'Thank you! ...') and change the string. You can also use the successCallback JS option to show a custom UI.

Can I store files outside public_html?

Yes. Set NF_UPLOAD_DIR to an absolute path outside the web root, e.g. /home/user/private_uploads/. Files won't be directly accessible via URL, which is safer.

Does it work on Windows/IIS?

Yes. Disable .htaccess (not supported on IIS) and use web.config for equivalent URL rules. SQLite and mail() work the same. Use SMTP for email on IIS environments.

How do I use PHPMailer instead of the built-in SMTP?

// 1. Install via Composer
composer require phpmailer/phpmailer

// 2. Replace sendSmtp() in nexform/Mailer.php with:
use PHPMailer\PHPMailer\PHPMailer;
$mail = new PHPMailer(true);
$mail->isSMTP();
$mail->Host       = NF_SMTP_HOST;
$mail->SMTPAuth   = true;
$mail->Username   = NF_SMTP_USERNAME;
$mail->Password   = NF_SMTP_PASSWORD;
$mail->SMTPSecure = NF_SMTP_ENCRYPTION;
$mail->Port       = NF_SMTP_PORT;
$mail->setFrom(NF_MAIL_FROM_EMAIL, NF_MAIL_FROM_NAME);
$mail->addAddress($to);
$mail->Subject = $subject;
$mail->isHTML(true);
$mail->Body = $body;
return $mail->send();
